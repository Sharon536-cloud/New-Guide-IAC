# מתכנן 40 שעות

דף אינטרנט בודד לתכנון שבוע העבודה: לכל יום (א׳–ו׳) מזינים שעת כניסה ויציאה,
עם אפשרות לפיצול משמרת. הדף מסכם את השעות ומראה כמה חסר או עודף מול יעד של 40 שעות.

- הנתונים נשמרים בדפדפן (localStorage) בלבד.
- שעות החוזה משמשות ברירת מחדל לכל שבוע חדש, וניתן לערוך אותן בהגדרות.
- "העתקת סיכום השבוע" מכינה טקסט מוכן להדבקה בוואטסאפ.

להפעלה: לפתוח את `index.html` בדפדפן, או להפעיל GitHub Pages על הריפו.
